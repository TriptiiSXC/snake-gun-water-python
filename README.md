Snake Gun Water Game

A beginner Python command-line game inspired by the traditional Snake, Gun and Water game.

About

I built this project while learning Python fundamentals and practicing conditional statements, user input, variables, and basic game logic.

This repository contains diiferent versions/methods of implementing the game

Features

- Player vs computer
- Snake, Gun and Water choices
- Win/lose/draw result
- Simple command-line interface
- Multiple implementation for learning and comparison

Technologies Used

- Python

How to Run

1. Make sure Python is installed.
2. Open the project folder in a terminal.
3. Run:

python main.py
